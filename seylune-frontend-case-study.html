01 — Project Context

A fictional brand, but a real frontend exercise.

The assignment required a company website, so the team had to choose a business direction and build a browser-accessible frontend. We chose fashion because we had already explored clothing through the Joey Clothing project, and that gave us a stronger starting point for product categories, visual direction, and customer flow.

Seylune is not an existing business. It is a concept brand created for the assignment. The final work focuses on frontend structure, page consistency, visual storytelling, and a complete browsing experience without backend checkout or database features.

Truth 01

Academic concept.

The brand was invented for the IAD Web Development group assignment, not presented as a real client brand.

Truth 02

Frontend only.

The required scope was HTML, CSS, JavaScript, responsive browser access, and interface interactions.

Truth 03

AI-assisted workflow.

Claude was used for coding assistance, while Gemini / Nano Banana supported model imagery and visual assets.

Truth 04

Solo final push.

Although assigned as a group project, the final page build, assembly, structure, and polish were handled under time pressure.

02 — Brand Origin

The name needed to feel Sri Lankan, feminine, and premium.

The name became the foundation for the visual system. Instead of choosing a random fashion name, Seylune was built from meaning: a local hint, a moon reference, and a feminine luxury mood.

Name System
Seylune
Sey

A subtle hint toward Ceylon, giving the name a soft Sri Lankan connection without making it too literal.

Lune

Moon-inspired language, used to create a feminine, elegant, and night-luxury feeling.

Result

A fashion identity that feels calm, premium, and slightly mysterious — less like a normal store and more like a curated collection.

Positioning

Luxury for the modern muse.

The brand voice was shaped around elegance, restraint, and a curated customer journey rather than loud discounts or crowded retail energy.

Inspiration

Joey helped choose the direction.

After working with a clothing-related UX project, fashion felt like the strongest business category to turn into a full frontend website.

Audience

Premium female fashion customers.

The website language, imagery, categories, and spacing were designed to feel polished and selective for a modern fashion buyer.

03 — Visual Direction

Most fashion sites go white. Seylune went dark, purple, and gold.

The goal was to avoid the usual clean-white fashion website look. Seylune uses dark purple, antique gold, moon tones, and premium interior-style model imagery to create a more editorial and limited feeling. The design avoids unnecessary animations so the brand feels calm instead of noisy.

Decision 01

Premium darkness

The darker base separates Seylune from typical white fashion stores and helps the gold accents feel richer.

Decision 02

Generated models

Fashion model visuals were created with Gemini / Nano Banana, with an Asian model direction and premium interiors.

Decision 03

No animation noise

The page keeps motion controlled so the website feels more luxury editorial than playful or overloaded.

04 — Website Structure

Started as eight pages. Finished as a twelve-page frontend.

The final structure grew beyond the minimum requirement. Instead of only building the core pages, the project added product detail pages and a search results page to make the browsing experience feel more complete.

06 — Category Strategy

Less categories made the store feel more curated.

Instead of adding too many categories, the website focuses on selected shopping paths: New Arrivals, Dresses, Tops, and Bottoms. This keeps the user journey simple and gives the brand a limited-collection feeling.

08 — Workflow & Tools

AI was used as an assistant, not as a fake credit.

The build used modern AI-assisted workflow honestly: Claude AI Sonnet 4.6 Adaptive helped with frontend code generation and iteration, while Gemini / Nano Banana helped generate fashion model imagery. The creative direction, page decisions, final structure, edits, visual judgement, file assembly, and polishing were handled manually in Visual Studio Code.

Tool 01

HTML

Used for page structure, navigation, product sections, forms, and page content.

Tool 02

CSS

Used for the luxury theme, responsive layout, spacing, typography, product grids, and interactions.

Tool 03

JavaScript

Used for frontend interactions required by the assignment and shopping-interface behavior.

Tool 04

AI workflow

Claude supported code iteration; Gemini / Nano Banana supported model and fashion visual generation.

Seylune became more than a class website. It became a test of how fast a concept brand can turn into a structured, consistent, and presentation-ready frontend experience.

09 — Reflection

What the project taught me.

Seylune was built under time pressure, so the strongest learning was not only frontend coding. It was learning how to make quick decisions, keep visual consistency, use AI responsibly, and still explain the work honestly in a portfolio.

01

Concept matters.

A fictional brand becomes stronger when the name, color, categories, imagery, and page flow all follow one idea.

02

Limited can feel premium.

Reducing categories helped the shopping experience feel curated instead of crowded.

03

AI needs direction.

The tools were useful only because the project had a clear mood, page plan, and final editing process.

04

Next step.

A future version could add backend cart logic, checkout, product filtering, accessibility testing, and a real hosted demo.
