FORGE Studio — built to move.

A personal studio identity shaped around energy, speed, and creative momentum — a sharp lightning mark carrying the hidden letter F.

DisciplineBrand Identity
Year2025—Now
OutputLogo System

01 — Foundation

The mark had to feel fast, sharp, and forged.

The FORGE Studio logo is a minimal construction that combines a lightning direction with a hidden F. The result is a symbol that feels energetic without becoming decorative.

The full identity is intentionally lean: a bold mark, a clear wordmark, a warm gold-orange palette, and strict layout rules that keep the system clean across print, digital, and app environments.

N° 01

Energy first.

The lightning form creates instant motion and gives the studio a more active, memorable personality.

N° 02

Hidden F.

The structure subtly forms the letter F, keeping the symbol connected to the FORGE name.

N° 03

Angular logic.

Sharp cuts and controlled angles reinforce strength, precision, and a crafted studio language.

N° 04

Flexible use.

Unnecessary details are removed so the logo stays clear in thumbnails, headers, signage, and mockups.

02 — Primary Mark

A bold symbol that works as both brand mark and app icon.

The symbol can stand alone when space is limited, or pair with the FORGE Studio wordmark when the brand name needs to be clear. Its gradient is used only inside the symbol, never across body text, so readability stays strong.

Primary symbolLightning movement + hidden F
03 — Logo Concept

A construction grid that makes the symbol feel intentional.

The FORGE mark is not only a lightning shape. It is built from controlled diagonal guides that help the symbol hold a strong direction, clear proportions, and a sharp visual rhythm.

The grid explains how the main angles, intersections, and negative spaces work together. This gives the logo a crafted feeling while keeping it stable enough for large brand displays and tiny app icons.

Construction board

Logo Grid System

Angular / Scalable

The logo is constructed using a structured angular grid system inspired by the natural direction and movement of lightning.

Diagonal guide lines define the symbol’s primary angles, proportions, and intersections, keeping the form balanced and consistent.

The angles reinforce energy, motion, and precision while giving the mark a controlled, intentional structure.

The grid helps the logo remain stable, scalable, and visually coherent across large formats, thumbnails, and digital icons.

04 — Lockups & Rules

Approved versions protect the logo from random use.

The identity includes primary, stacked, icon-only, and monochrome lockups. Minimum size and clear-space rules keep the mark readable even when it appears inside tight layouts.

Logo lockupsPrimary / stacked / icon / mono
Clear spaceMinimum size rules
Rule 01

Keep clear space.

A minimum clear space equal to the upper height of the symbol should stay around the logo. No extra element should enter this area.

Rule 02

Respect size.

Below the recommended minimum sizes, the symbol-only version should be used for better legibility.

Rule 03

Use approved lockups.

Primary, stacked, icon-only, and monochrome versions are the approved variations for brand consistency.

05 — Visual System

Color and type give the mark real working range.

The palette is intentionally minimal: Heated Gold, Ember Orange, and Forged Steel. Typography stays clean and neutral so the visual layouts can breathe while the mark carries the brand energy.
